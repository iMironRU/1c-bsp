## Документация платформы 8.3

```
~/Documents/github_dev/1c-syntax-helper-mcp/data/extracted/    231 МБ, 53 428 файлов
```

Распакована из `data/hbk/*.hbk` архиватором `7zz` — обычный HTML в UTF-8, ищется
грепом. Elasticsearch и Docker для этого не нужны. Пересобрать:

```bash
cd ~/Documents/github_dev/1c-syntax-helper-mcp/data/hbk
for f in *.hbk; do 7zz x "$f" -o"../extracted/${f%.hbk}" -y </dev/null; done
```

Оговорка: грепом ищется точное совпадение, морфологии нет — «подсистемы» не
найдёт «подсистеме». Для имён процедур, свойств и заголовков этого хватает.

## Почему остаёмся на 3.1.12

Есть и документация БСП 3.2.1 (`its.1c.ru/db/bsp321doc`), но эта редакция
рассчитана на платформу 8.5, а книга и всё проверенное — на 8.3. Заодно это
объясняет, почему конфигурации подолгу сидят на 3.1.x: библиотеку тянет вперёд не
желание разработчика, а версия платформы.

Адреса глав на ИТС (доступ по подписке):

```
its.1c.ru/db/content/bsp3112doc/src/глава 1. состав библиотеки.htm
its.1c.ru/db/content/bsp3112doc/src/глава 2. инструкция по внедрению библиотеки.htm
its.1c.ru/db/content/bsp3112doc/src/глава 3. настройка и использование подсистем при разработке конфигурации.htm
```

Всего глав пять плюс три приложения; не добыты глава 4 «Программный интерфейс» и
глава 5 «Пользовательская документация».
